# m1zuki для Windows

Основа — исходники из пользовательского `m1zuki.zip`, включая кнопки мыши и несколько вопросов в одном снимке. Linux-реализация сохранена; CMake выбирает платформенные модули.

## Запуск

Windows 10 2004 (сборка 19041) или новее, Windows 11, x64. Распакуйте **всю** папку `m1zuki-windows` (в релизе 1.4.0 — `m1zuki-windows-1.4.0`) и запустите `m1zuki.exe`. Qt и библиотеки компилятора находятся рядом; Python и KDE для запуска не нужны.

Введите свой ключ OpenRouter и сохраните настройки. По умолчанию `Ctrl+Alt+Space` получает ответ, `Ctrl+Alt+Backspace` скрывает ответ и отменяет ожидание. «Проверить» показывает пример без отправки снимка.

Кнопки средней мыши, Mouse4 и Mouse5 назначаются в настройках и действуют глобально, пока приложение работает. Назначенная кнопка не выполняет обычную функцию; после снятия привязки или выхода она восстанавливается. Закрытие настроек сворачивает приложение в трей. Выход — через меню трея или кнопку «Выйти».

Поддерживаются `--settings`, `--capture`, `--clear`, `--demo`, `--quit`, `--render-preview путь.png`. Повторный запуск передаёт команду работающему экземпляру. `mini-answer.exe` — совместимое прежнее имя той же программы.

Установка в меню «Пуск» без прав администратора:

```powershell
powershell -ExecutionPolicy Bypass -File .\install-windows.ps1
```

## Сборка из исходников

Нужны Python для первоначальной загрузки инструментов, Qt 6.8.3 и MinGW 13.1. Скрипт загружает Qt и MinGW в `.tools`, CMake/Ninja/aqtinstall устанавливает для текущего пользователя:

```powershell
powershell -ExecutionPolicy Bypass -File .\build-windows.ps1 -Bootstrap
```

Для последующих сборок уберите `-Bootstrap`. Скрипт запускает тесты и создаёт `dist/m1zuki-windows-x64.zip`. Можно передать собственные `-QtRoot` и `-MingwRoot`. CMake также поддерживает MSVC с соответствующей сборкой Qt.

## Сохранённые функции

Всплывающие системные уведомления отключены. Ошибка обозначается небольшим розовым «×» у верхнего левого края основного экрана на 5 секунд, без звука и перехвата мыши. Подробности можно посмотреть в настройках (`Ctrl+Alt+M`). Отмена и следующий запрос убирают значок. При недоступной защите записи показывается только этот общий знак ошибки; ответы остаются скрытыми.

Кнопка «Скрыть значок и окно» убирает m1zuki из трея и скрывает настройки, оставляя программу работающей. **Ctrl+Alt+M** возвращает окно даже без значка. В открытом окне кнопка «Показать значок трея» возвращает значок. Если сочетание занято, скрытие не выполняется. При следующем запуске значок снова виден. Повторный запуск `m1zuki.exe --settings` также возвращает окно.

* Русский интерфейс и трей, модель и ключ OpenRouter, проверка ответа, ошибки и отмена запроса.
* Один или несколько вопросов; один или несколько вариантов в каждом вопросе; прежние правила разбора ответов.
* Прозрачный оверлей на основном мониторе, без перехвата мыши и фокуса; время показа и размер шрифта.
* Снимок монитора под курсором или всего виртуального рабочего стола, включая мониторы с отрицательными координатами. Снимок хранится в памяти, без временного PNG на диске.
* Глобальные клавиши, средняя/боковые кнопки мыши, немедленное сохранение привязок мыши, откат при ошибке сохранения.
* Один экземпляр приложения и управление командами из другого процесса.
* Исключение собственных окон из поддерживаемых путей записи средствами Windows. При ошибке подтверждения защиты ответ скрывается.

## Отличия платформ и границы проверки

Исключение окон использует `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` вместо KWin. Microsoft не гарантирует защиту от всех методов захвата; конкретную программу записи/демонстрации необходимо проверить по её предпросмотру. Трей и системные уведомления принадлежат Windows и не исключаются. См. [документацию Microsoft](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity).

Оверлей работает поверх обычных и безрамочных полноэкранных окон. Эксклюзивный полноэкранный режим, защищённый рабочий стол UAC и приложения с особыми ограничениями ввода не имеют гарантии совпадения с KDE. Windows может резервировать сочетания клавиш (включая F12); занятые сочетания возвращают ошибку. Шрифты зависят от установленных в системе гарнитур.

Настройки: `%LOCALAPPDATA%/mini-answer/settings.json` (точный корень определяется Qt GenericConfigLocation), либо `XDG_CONFIG_HOME/mini-answer/settings.json`, если переменная задана. Каталог и файл защищаются Windows ACL для текущего пользователя и LocalSystem; ключ сохраняется как текст, как и в оригинале. Переменная `OPENROUTER_API_KEY` используется, если поле ключа пустое, и не записывается в настройки.

Автотесты OpenRouter используют подставные ответы: они не подтверждают работу конкретной модели или действительность API-ключа. Интеграционный тест Windows проверяет нативные окна, исключение из захвата, отсутствие фокуса и таймер скрытия. Разные DPI, несколько физических мониторов и сторонние программы записи требуют проверки на соответствующем оборудовании.
