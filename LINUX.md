# m1zuki для Linux / KDE Wayland

Linux-ветка включает последние общие изменения: скрытие значка трея и окна, возвращение настроек через **Ctrl+Alt+M**, тихий индикатор ошибки «×», отмену запроса, кнопки мыши и несколько вопросов в одном снимке. Клавиша возвращения окна проверяется перед скрытием значка. При ошибке старый ответ скрывается; системные уведомления не выводятся.

## Поддерживаемая среда

Основная цель — актуальные Arch Linux / CachyOS с KDE Plasma 6 и Wayland. Нужны Qt 6.5+, KDE Frameworks 6 GlobalAccel и Config, Spectacle. Нативное позиционирование поверх полноэкранных окон требует LayerShellQt с `Window::setScreen`; исключение из записи требует поддержки KWin `excludeFromCapture` (Plasma 6.7+). На старом KWin, X11 и других окружениях защита не подтверждается, поэтому ответы остаются скрытыми.

Пакет `m1zuki-linux-<архитектура>.tar.gz` содержит бинарник и ресурсы, но **не включает Qt/KDE**. Он предназначен для совместимой Linux-системы с установленными зависимостями; это не универсальный AppImage. Нельзя запускать пакет другой архитектуры.

## Сборка и проверка

На Arch/CachyOS:

```bash
sudo pacman -S --needed base-devel cmake qt6-base qt6-svg kglobalaccel kconfig layer-shell-qt spectacle python
bash build-linux.sh
```

Скрипт собирает Release, запускает CTest с `QT_QPA_PLATFORM=offscreen` и создаёт `dist/m1zuki-linux-$(uname -m).tar.gz`. Если установлен Node.js, дополнительно проверяется генерируемый KWin-скрипт без доступа к рабочему столу. Отдельно: `node tests/test_captureprotection_script.js`.

Для запуска из исходников: `bash run.sh`. Скрипт выполняет инкрементальную сборку при каждом запуске, поэтому изменения исходников не оставляют старый бинарник. Сборочный каталог по умолчанию — `build-linux`; переопределение: `M1ZUKI_BUILD_DIR`. Параллелизм: `CMAKE_BUILD_PARALLEL_LEVEL` (по умолчанию 2).

Установка из исходников: `bash install.sh`. Она собирает и проверяет приложение, затем устанавливает его в `~/.local/bin` и добавляет пункт меню KDE.

## Установка готового Linux-пакета

```bash
tar -xzf m1zuki-linux-x86_64.tar.gz
cd m1zuki-linux-x86_64
bash install-package.sh
```

Зависимости должны быть установлены заранее. Перед обновлением завершите работающий m1zuki через «Выйти»; после установки запустите его снова. Установщик работает для текущего пользователя без `sudo`, сохраняет пользовательские настройки и совместимое имя `mini-answer`. Можно задать `M1ZUKI_INSTALL_PREFIX` для другого каталога установки.

## Проверка в реальном сеансе

Автотесты проверяют разбор ответов, ошибки API, настройки, отмену снимка, восстановление кнопок мыши и сам KWin-скрипт. Они не заменяют проверку KDE Wayland, реальной клавиатуры/мыши, нескольких мониторов и конкретной программы видеозаписи.

После запуска нажмите «Проверить»: пример должен отображаться на мониторе, но отсутствовать в предпросмотре выбранной программы захвата. Для локального интеграционного теста:

```bash
python3 tests/run_privacy_probe.py build-linux/privacy_probe --output-dir build-linux/privacy-check
```

Этот тест требует активного KDE Wayland, Python с Pillow/numpy и Spectacle. Аппаратный захват, фотографирование экрана и неподдерживаемые пути записи не покрываются исключением KWin. Ключ OpenRouter и реальные снимки не используются обычными автоматическими тестами.
