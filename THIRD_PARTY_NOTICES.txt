The Windows and macOS release packages dynamically link the unmodified Qt 6.8.3
libraries (Qt Base and Qt SVG). Windows packages include shared DLLs; macOS
packages include shared frameworks/libraries and plugins in the application bundle.
Qt copyright: The Qt Company Ltd. and other contributors.
Qt libraries used here are available under GNU LGPL version 3; the LGPL and GPL
texts are supplied in licenses/. You may replace the shared Qt libraries with
compatible modified versions. The application build scripts and sources are
provided alongside the packages in the source archive/workspace. A rebuilt macOS
bundle may need to be signed again after replacing its shared libraries.

Linux packages use the Qt and KDE libraries installed on the target system and
do not bundle them. Their versions, source packages and license notices are
provided by the Linux distribution. Custom builds may use a different Qt version.
