# m1zuki для macOS

Порт рассчитан на macOS 13+, Apple Silicon (arm64) и Intel (x86_64). Общие функции сохранены: OpenRouter, несколько вопросов, оверлей, отмена, настройки, меню в строке состояния, скрытие значка, тихий «×» при ошибке. Состояние проверки конкретной сборки смотрите в BUILD-STATUS.md.

## Существенное отличие

macOS не предоставляет гарантированного аналога исключения окна из всех способов записи. Apple описывает `NSWindowSharingNone` как устаревший неиспользуемый механизм: https://developer.apple.com/documentation/appkit/nswindow/sharingtype-swift.enum

По умолчанию ответы не показываются. Для обычного использования включите в настройках **«Разрешить показ без защиты от записи»** и сохраните. Ответы и настройки при этом могут попадать в запись и демонстрацию экрана. Эта опция относится только к Mac; Windows/KDE сохраняют прежнюю проверку защиты.

## Запуск и разрешения

Распакуйте `m1zuki.app`, перенесите в `~/Applications` и запустите. Для снимков нужен доступ к записи экрана в системных настройках конфиденциальности. Для глобальных кнопок мыши могут потребоваться разрешения Accessibility/Input Monitoring; клавиатурные сочетания работают отдельно. После изменения разрешений может потребоваться перезапуск приложения.

В обозначениях Qt на Mac `Ctrl` соответствует Command, `Meta` — физической Control, а `Alt` — Option. По умолчанию: **Control+Option+Space** — запрос, **Control+Option+Delete** — скрытие/отмена, **Command+Option+M** — вернуть настройки. Клавиши запроса и отмены можно изменить, если они заняты системой. Значок находится в строке меню; приложение не занимает место в Dock.

Ключ и настройки находятся в `~/Library/Preferences/mini-answer/settings.json` (корень Qt GenericConfigLocation), либо в каталоге `XDG_CONFIG_HOME`, если он задан. Ключ хранится локально как текст с ограниченными правами; можно оставить поле пустым и использовать `OPENROUTER_API_KEY`.

## Сборка на Mac

Установите Xcode Command Line Tools, CMake, Ninja и Qt 6.5+ (например, `brew install cmake ninja qt`). Затем:

```sh
bash build-macos.sh
```

Для собственной установки Qt: `QT_ROOT=/путь/к/Qt/6.8.3/macos bash build-macos.sh`.
Для универсального пакета нужна Qt с обеими архитектурами:

```sh
QT_ROOT=/путь/к/Qt/6.8.3/macos M1ZUKI_MAC_ARCHS='arm64;x86_64' bash build-macos.sh
```

Скрипт собирает `.app`, запускает тесты, включает Qt через `macdeployqt` и создаёт ZIP в `dist`. Подпись локальная ad-hoc, не Developer ID; нотариального подтверждения Apple нет. Для публичного распространения разработчику нужны собственные сертификат Developer ID и notarization. Скрипт не отключает Gatekeeper и не меняет настройки безопасности.
