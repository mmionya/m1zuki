# m1zuki

Ранее приложение называлось Mini Answer. При обновлении ключ, настройки и сочетания клавиш сохраняются; старая команда `mini-answer` остаётся совместимым ярлыком для `m1zuki`.

Нативное приложение для Linux / KDE Plasma: по горячей клавише снимает экран, отправляет его в OpenRouter и показывает **номера правильных ответов в левом верхнем углу основного монитора**. Оверлей прозрачный, пропускает нажатия мыши и не забирает фокус. Работает поверх полноэкранных окон в KDE Wayland через LayerShellQt.

**Версия 1.3:** компактные настройки в тёмной теме с розовыми акцентами, без вводных заголовков и поясняющих абзацев. Служебные состояния доступны в подсказке значка в трее; ошибки появляются в окне настроек. Иконка использует изображение, выбранное пользователем; источник и автор указаны в `assets/mini-answer-character-credits.txt`.

**Версия 1.2:** поддерживаются вопросы с одним или несколькими правильными вариантами. Один ответ отображается как `3`, несколько — как `1, 3, 4`. Модель определяет тип вопроса по инструкции и видимым элементам выбора; отдельный переключатель не нужен.

**Версия 1.1:** окна m1zuki исключаются из захвата монитора и области через KDE/PipeWire. На физическом мониторе цифра остаётся видимой. До подтверждения KWin цифра не показывается.

## Запуск

```bash
./run.sh
```

В открывшихся настройках вставьте ключ OpenRouter, при необходимости измените ID модели и нажмите **«Сохранить»**. Настройки сохранятся, а окно свернётся в трей. Подойдёт модель с поддержкой изображений; по умолчанию указана `google/gemini-2.5-flash-lite`. Вместо сохранения ключа можно задать переменную окружения `OPENROUTER_API_KEY` перед запуском. Подписка на чат не заменяет API-ключ и баланс OpenRouter.

| Действие | Сочетание по умолчанию |
| --- | --- |
| Снять экран и получить ответ | `Ctrl+Alt+Space` |
| Скрыть цифру / отменить запрос | `Ctrl+Alt+Backspace` |

Вопрос и все варианты должны быть видны на экране. По умолчанию снимается монитор под указателем мыши. В настройках можно включить весь рабочий стол, изменить клавиши, размер цифры и время её показа (по умолчанию 15 секунд). При конфликте клавиш программа сообщит об этом — выберите другое сочетание.

Для буквенных вариантов `A, B, C…` или `А, Б, В…` показывается порядковый номер `1, 2, 3…`. Несколько правильных вариантов выводятся через запятую, по возрастанию и без повторов. Длинный список переносится на следующую строку. Если вопрос не читается или модель не может определить полный набор ответов, номера не показываются. Ошибка доступна через значок в системном лотке и окно настроек. Ответ модели может быть неверным.

Кнопка **«Проверить»** показывает тестовые номера `1, 3, 4` без снимка и обращения к API. Настройки открываются нажатием на значок в лотке или повторным запуском приложения. Закрытие окна сворачивает приложение в лоток; для завершения выберите **«Выйти»**.

## Установка в меню приложений

```bash
./install.sh
```

Установка выполняется для текущего пользователя, без `sudo`: бинарный файл в `~/.local/bin/m1zuki`, ярлык в пользовательском каталоге приложений. После установки откройте **m1zuki** из меню KDE.

Дополнительные команды:

```bash
./run.sh --settings
./run.sh --capture
./run.sh --clear
./run.sh --demo
./run.sh --quit
```

Повторный запуск передаёт команду уже открытому приложению. Команду `--capture` можно также назначить на сочетание клавиш средствами рабочего стола.

## Сборка и зависимости

Нужны C++17, CMake, Qt 6.5+ (Widgets, Network, DBus, Test), KDE Frameworks 6 GlobalAccel и Spectacle. Для нативного оверлея Wayland нужен LayerShellQt с методом `Window::setScreen` (Plasma 6.6+). Защищённый показ требует сеанса KDE Wayland и свойства KWin `excludeFromCapture`. Проверено на KDE 6.7.5. На X11, в других средах или при ошибке защиты приложение оставляет оверлей скрытым.

На CachyOS / Arch названия пакетов: `base-devel cmake qt6-base kglobalaccel layer-shell-qt spectacle`. На данном компьютере необходимые библиотеки уже были установлены.

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
```

Автоматические тесты используют подставные ответы API и искусственные изображения; реальный ключ и снимок рабочего стола им не нужны. Для изображения окна настроек:

```bash
QT_QPA_PLATFORM=offscreen ./build/m1zuki --render-preview build/settings-preview.png
```

## Данные и ограничения

Каждое нажатие клавиши отправляет один снимок через HTTPS в OpenRouter и выбранному поставщику модели. Постоянного наблюдения, записи звука и истории снимков нет. Временный файл Spectacle удаляется после чтения, ошибки или отмены. При аварийном завершении процесса временная папка может остаться в `/tmp/minianswer-*`.

Настройки и API-ключ сохраняются в `~/.config/mini-answer/settings.json` (либо в `$XDG_CONFIG_HOME/mini-answer/settings.json`) с правами `0600`; это локальный файл, не зашифрованное хранилище. Ключ и содержимое экрана не выводятся в журнал. Для изменения без сохранения ключа в файле очистите поле и используйте переменную окружения. Отмена прекращает локальное ожидание, но уже отправленный запрос может быть обработан и тарифицирован сервисом.

Поддерживается один вопрос за запрос, с одним или несколькими правильными вариантами. Набор номеров появляется целиком после завершения обработки; во время ожидания предыдущий ответ скрывается. Нечёткие ответы вроде «1 или 3», диапазоны и поясняющий текст не превращаются в список вариантов.

## Скрытие из записи и демонстрации экрана

Приложение подключает временный KWin-скрипт, который устанавливает `excludeFromCapture` только окнам собственного процесса m1zuki. Другие окна и системные правила не меняются. Модуль загружается при запуске и выгружается при нормальном завершении. Новые окна получают свойство при добавлении в KWin, до отрисовки следующего кадра. Состояние подтверждается через D-Bus; при ошибке или перезапуске KWin цифра скрывается.

В браузере или приложении звонков выбирайте **захват монитора/экрана через KDE/PipeWire**. Этот путь исключает защищённые окна; захват области через KDE тоже поддерживается. В KDE 6.7 защита распространяется также на снимки Spectacle. Явный захват отдельного окна m1zuki, аппаратный захват, фото монитора и иные пути записи этой гарантией не покрываются. Значок в системном лотке и уведомления принадлежат оболочке KDE и не скрываются.

Перед важной демонстрацией проверьте её предпросмотр кнопкой «Проверить»: цифра должна быть на мониторе, но отсутствовать в передаваемом изображении. Сведения о штатной функции: [изменения KDE 6.7](https://blogs.kde.org/2026/05/16/this-week-in-plasma-6.7-beta-release/).

Ручная интеграционная проверка на рабочем столе с одним монитором:

```bash
python3 tests/run_privacy_probe.py build/privacy_probe --output-dir build/privacy-check
```

Она временно рисует одноцветный прямоугольник в углу, сравнивает снимки с обычной и защищённой цифрой и сохраняет только вырезку тестовой области. Нужны Python, Pillow и numpy. На данном компьютере: 3068 изменённых пикселей для обычного оверлея и 0 для защищённого; защищённое окно при этом было отображено композитором. Это проверка пути Spectacle/KWin, не конкретного браузера или видеозвонка.

Технические справочники: [изображения в OpenRouter API](https://openrouter.ai/docs/guides/overview/multimodal/image-understanding), [KGlobalAccel](https://api.kde.org/kglobalaccel.html), [LayerShellQt](https://invent.kde.org/plasma/layer-shell-qt).
