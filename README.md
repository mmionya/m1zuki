# m1zuki

**m1zuki 1.4.0** — приложение для Windows, Linux / KDE Plasma и macOS на основе предоставленного архива. По горячей клавише снимает экран, отправляет его в OpenRouter и показывает **номера правильных ответов в левом верхнем углу основного монитора**. Прозрачный оверлей пропускает нажатия мыши и не забирает фокус.

| Платформа | Запуск, сборка и ограничения |
| --- | --- |
| Windows x64 | [WINDOWS.md](WINDOWS.md) |
| Linux / KDE Wayland | [LINUX.md](LINUX.md) |
| macOS 13+, Apple Silicon и Intel | [MACOS.md](MACOS.md) |

Результаты проверки сборок и границы автоматических тестов описаны в [BUILD-STATUS.md](BUILD-STATUS.md). Проверка сборки не заменяет проверку записи экрана на конкретном рабочем столе.

На Windows и поддерживаемом KDE Wayland ответы показываются только после подтверждения исключения окна из записи. **На macOS аналогичная защита недоступна:** показ ответов требует явного включения «Разрешить показ без защиты от записи». Подробности — в инструкции соответствующей платформы.

Ранее приложение называлось Mini Answer. При обновлении ключ, настройки и сочетания клавиш сохраняются; старая команда `mini-answer` остаётся совместимым ярлыком для `m1zuki`.

В версии 1.4.0 можно скрыть значок трея вместе с окном и вернуть настройки глобальным сочетанием клавиш. Всплывающих уведомлений нет: при ошибке прежний ответ скрывается, а у края экрана на 5 секунд появляется небольшой розовый «×». Подробности доступны в настройках. Отмена и следующий запрос убирают знак ошибки.

Поддерживаются несколько вопросов в одном снимке и один или несколько правильных вариантов на вопрос. Большие снимки отправляются несколькими перекрывающимися фрагментами. Ответы показываются по порядку чтения: `Q1: 3`, `Q2: 1, 4`; если ответ на вопрос определить не удалось, показывается `?`.

Настройки используют тёмную тему с розовыми акцентами. Иконка использует изображение, выбранное пользователем; источник и автор указаны в [assets/mini-answer-character-credits.txt](assets/mini-answer-character-credits.txt).

## Запуск на Linux

```bash
bash run.sh
```

В открывшихся настройках вставьте ключ OpenRouter, при необходимости измените ID модели и нажмите **«Сохранить»**. Настройки сохранятся, а окно свернётся в трей. Подойдёт модель с поддержкой изображений; по умолчанию указана `google/gemini-2.5-flash-lite`. Вместо сохранения ключа можно задать переменную окружения `OPENROUTER_API_KEY` перед запуском. Подписка на чат не заменяет API-ключ и баланс OpenRouter.

| Действие | Сочетание по умолчанию |
| --- | --- |
| Снять экран и получить ответ | `Ctrl+Alt+Space` |
| Скрыть цифру / отменить запрос | `Ctrl+Alt+Backspace` |
| Вернуть настройки при скрытом значке | `Ctrl+Alt+M` |

Эти сочетания по умолчанию относятся к Linux и Windows; клавиши macOS описаны в [MACOS.md](MACOS.md).

Вопрос и все варианты должны быть видны на экране. По умолчанию снимается монитор под указателем мыши. В настройках можно включить весь рабочий стол, изменить клавиши, размер цифры и время её показа (по умолчанию 15 секунд). При конфликте клавиш программа сообщит об этом — выберите другое сочетание.

В KDE Wayland для каждого действия можно дополнительно выбрать в отдельном списке **«Кнопка мыши»** нажатие на колёсико (среднюю кнопку), **Mouse 4 (назад)** или **Mouse 5 (вперёд)**. Выбор кнопки мыши сохраняется и применяется сразу, независимо от полей сочетаний клавиш выше. Выбранная кнопка работает во всех окнах, пока m1zuki запущен. Для боковых кнопок обычное действие «назад/вперёд» на это время заменяется; нажатие колёсика назначается глобально как средняя кнопка. При отключении привязки или выходе из приложения прежнее назначение восстанавливается. После аварийного завершения восстановление выполняется при следующем запуске. Изменения, сделанные в настройках мыши KDE во время работы приложения, сохраняются.

Для буквенных вариантов `A, B, C…` или `А, Б, В…` показывается порядковый номер `1, 2, 3…`. Несколько правильных вариантов выводятся через запятую, по возрастанию и без повторов. Ответы `Q1`, `Q2` и т. д. идут сверху вниз, затем слева направо; длинный список переносится на следующую строку. Если вопрос не читается или модель не может определить ответ, для него показывается `?`, чтобы было видно соответствие с вопросом. При ошибке появляется «×»; текст ошибки можно прочитать, открыв настройки. Ответ модели может быть неверным.

Кнопка **«Проверить»** показывает тестовые номера `1, 3, 4` без снимка и обращения к API. Настройки открываются нажатием на значок в лотке или повторным запуском приложения. Закрытие окна сворачивает приложение в лоток; для завершения выберите **«Выйти»**.

Кнопка **«Скрыть значок и окно»** оставляет программу работающей без значка трея. **Ctrl+Alt+M** возвращает настройки; кнопка **«Показать значок трея»** возвращает значок. Если глобальная клавиша возвращения окна недоступна, скрытие не выполняется. При следующем запуске значок снова виден.

## Установка в меню приложений Linux

```bash
bash install.sh
```

Установка выполняется для текущего пользователя, без `sudo`: бинарный файл в `~/.local/bin/m1zuki`, ярлык в пользовательском каталоге приложений. После установки откройте **m1zuki** из меню KDE.

Дополнительные команды:

```bash
bash run.sh --settings
bash run.sh --capture
bash run.sh --clear
bash run.sh --demo
bash run.sh --quit
```

Повторный запуск передаёт команду уже открытому приложению. Команду `--capture` можно также назначить на сочетание клавиш средствами рабочего стола.

## Сборка и зависимости Linux

Нужны C++17, CMake, Qt 6.5+ (Widgets, Network, DBus, Test), KDE Frameworks 6 GlobalAccel, KConfig и Spectacle. Для нативного оверлея Wayland нужен LayerShellQt с методом `Window::setScreen`. Защищённый показ требует сеанса KDE Wayland и свойства KWin `excludeFromCapture` (Plasma 6.7+). На X11, в других средах или при ошибке защиты приложение оставляет ответы скрытыми.

На CachyOS / Arch названия пакетов: `base-devel cmake qt6-base qt6-svg kglobalaccel kconfig layer-shell-qt spectacle python`. Команда `bash build-linux.sh` собирает приложение, запускает тесты и создаёт `dist/m1zuki-linux-$(uname -m).tar.gz`. Пакет требует установленных Qt/KDE и совместимой системы. Подробности — в [LINUX.md](LINUX.md).

```bash
cmake -S . -B build-linux -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build-linux --parallel 2
QT_QPA_PLATFORM=offscreen ctest --test-dir build-linux --output-on-failure
```

Автоматические тесты используют подставные ответы API и искусственные изображения; реальный ключ и снимок рабочего стола им не нужны. Для изображения окна настроек:

```bash
QT_QPA_PLATFORM=offscreen ./build-linux/m1zuki --render-preview build-linux/settings-preview.png
```

## Данные и ограничения

Каждое нажатие клавиши отправляет один снимок через HTTPS в OpenRouter и выбранному поставщику модели. Постоянного наблюдения, записи звука и истории снимков нет. Временный файл Spectacle удаляется после чтения, ошибки или отмены. При аварийном завершении процесса временная папка может остаться в `/tmp/minianswer-*`.

На Linux настройки и API-ключ сохраняются в `~/.config/mini-answer/settings.json` (либо в `$XDG_CONFIG_HOME/mini-answer/settings.json`) с правами `0600`; это локальный файл, не зашифрованное хранилище. Пути Windows и macOS указаны в соответствующих инструкциях. Ключ и содержимое экрана не выводятся в журнал. Для изменения без сохранения ключа в файле очистите поле и используйте переменную окружения. Отмена прекращает локальное ожидание, но уже отправленный запрос может быть обработан и тарифицирован сервисом.

Поддерживаются несколько вопросов за запрос, с одним или несколькими правильными вариантами. Набор номеров появляется целиком после завершения обработки; во время ожидания предыдущий ответ скрывается. Нечёткие ответы вроде «1 или 3», диапазоны и поясняющий текст не превращаются в список вариантов.

## Скрытие из записи и демонстрации экрана на KDE Wayland

Приложение подключает временный KWin-скрипт, который устанавливает `excludeFromCapture` только окнам собственного процесса m1zuki. Другие окна и системные правила не меняются. Модуль загружается при запуске и выгружается при нормальном завершении. Новые окна получают свойство при добавлении в KWin, до отрисовки следующего кадра. Состояние подтверждается через D-Bus; при ошибке или перезапуске KWin цифра скрывается.

В браузере или приложении звонков выбирайте **захват монитора/экрана через KDE/PipeWire**. Этот путь исключает защищённые окна; захват области через KDE тоже поддерживается. В KDE 6.7 защита распространяется также на снимки Spectacle. Явный захват отдельного окна m1zuki, аппаратный захват, фото монитора и иные пути записи этой гарантией не покрываются. Значок в системном лотке принадлежит оболочке KDE и не скрывается защитой окна; его можно убрать кнопкой «Скрыть значок и окно».

Перед важной демонстрацией проверьте её предпросмотр кнопкой «Проверить»: цифра должна быть на мониторе, но отсутствовать в передаваемом изображении. Сведения о штатной функции: [изменения KDE 6.7](https://blogs.kde.org/2026/05/16/this-week-in-plasma-6.7-beta-release/).

Ручная интеграционная проверка на рабочем столе с одним монитором:

```bash
python3 tests/run_privacy_probe.py build-linux/privacy_probe --output-dir build-linux/privacy-check
```

Она временно рисует одноцветный прямоугольник в углу, сравнивает снимки с обычной и защищённой цифрой и сохраняет только вырезку тестовой области. Нужны Python, Pillow и numpy. Это проверка пути Spectacle/KWin, не конкретного браузера или видеозвонка. Для версии 1.4.0 проверка на живом рабочем столе KDE в рамках этого обновления не проводилась; автоматические результаты и оставшиеся ручные проверки описаны в [BUILD-STATUS.md](BUILD-STATUS.md).

Технические справочники: [изображения в OpenRouter API](https://openrouter.ai/docs/guides/overview/multimodal/image-understanding), [KGlobalAccel](https://api.kde.org/kglobalaccel.html), [LayerShellQt](https://invent.kde.org/plasma/layer-shell-qt).
